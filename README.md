# auto-wanan

小遊戲 : [借用凱達格蘭大道大作戰
](https://sansword.github.io/no_party_for_wanna/)

## 啟動指令

```bash
py main.py
```

## `-np` 參數使用方式

使用 `-np` 指定並行玩家名稱（以逗號 `,` 分隔），會同時開啟對應數量的並行執行緒分別送出請求；若名稱內含空白，可用雙引號 `"..."` 括起來：

```bash
py main.py -np xxx,yyy,zzz
py main.py -np '"player one","player two",player3'
```

## 自動校準系統概述

- **連線與計時基準**：在送出 `POST /api/runs` 前預先建立 TLS/HTTP 連線，並於送出瞬間起算時間；倒數前 50 ms 停止刷新終端進度條以避免 I/O 延遲，最後區段以高精準等待對齊目標送出時刻。
- **自適應步進（初期／未取得伺服器時間）**：以 `+0.5 ms` 起始緩衝搭配往返時間（RTT）抖動估計；若回傳 `too_fast` 則自動微幅上調偏移，通過 15 秒檢查後逐步下修逼近下緣，整體偏差上限鎖定於 `±1 ms`。
- **95% 單尾信賴區間對齊（取得 `record.timeMs` 後）**：累積 2 筆以上伺服器回傳時間後，計算「伺服器實際耗時 − 計畫間隔」的中位數偏差與樣本標準差，以 `15 s − 中位數偏差 + 95% 單尾 t 信賴區間緩衝` 自動補償下一輪目標間隔，並將緩衝與目標偏差限制在 `±1 ms` 內。
